# Vendor Security Assessment

This work sample demonstrates a structured third-party security assessment of Amazon Web Services (AWS) as a representative critical cloud provider.

The assessment is based exclusively on publicly available evidence and covers key areas including security governance, information security, privacy, identity and access management, incident management, business continuity, compliance, third-party risk, and AI governance.

The workbook includes:

- 20 control questions
- Evidence references and source validation
- Assessment notes
- Reviewer outcomes
- Assurance scoring
- Follow-up requirements
- Final vendor decision

The assessment is designed as a portfolio work sample demonstrating practical Vendor Risk, GRC, and Security Compliance analysis.
